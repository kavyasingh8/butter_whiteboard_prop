# butter_whiteboard_prop

Whiteboard props for FiveM. They come in two variants, one for walls and one on a stand.

## Props

| Model | Description |
| --- | --- |
| `butter_whiteboard_wall` | Wall-mounted whiteboard |
| `butter_whiteboard_stand` | Freestanding whiteboard on a stand |

## Installation

1. Place `butter_whiteboard_prop` in your `resources` folder.
2. Add it to your `server.cfg`:

```cfg
ensure butter_whiteboard_prop
```

Start it before any resource that spawns these models.
